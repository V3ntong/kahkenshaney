2. The "Humanized Empty States" Prompt
Use this for screens with no data (like an empty chat history, empty cart, or search with zero results) to replace boring grey text with something engaging.

"Design a warm, human-centric empty state. Instead of a generic 'No items found', include a friendly, context-relevant illustration or clean vector icon, a short conversational explanation text, and a prominent, highly actionable CTA button that guides the user on what to do next (e.g., 'No messages yet—start the conversation!')."

3. The "Skeleton & Shimmer Loading" Prompt
Use this to kill boring blank-screen loading lags and spinners.

"Implement smooth shimmer skeleton loaders that closely mimic the exact shape of the incoming content layout (cards, avatars, text lines) rather than using a generic center spinner. This creates a perceived performance boost and keeps the user visually anchored while data fetches."
